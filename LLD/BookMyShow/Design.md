## Requirements
```
    Core Features
1. Search movies by city
2. View theatres/shows
3. Select seats
4. Lock seats temporarily
5. Make payment
6. Confirm booking
7. Cancel booking

    Non-Functional Requirements
1. No double booking
2. Concurrency handling
3. Seat locking with timeout
4. Consistency of booking state
5. Extensible payment system
6. Scalability for many concurrent users
7. Failure handling
```
